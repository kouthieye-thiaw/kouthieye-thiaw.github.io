| Fichier | Rôle |

| `index.html` | le portfolio : projets, trois univers (énergie, électronique, automatisme), compétences, certifications, parcours, engagement, passions, mannequinat, CV, contact |

| `assets/js/main.js` · `assets/js/pcb.js` | les animations (GSAP, ScrollTrigger, Lenis) |
| `assets/js/univers.js` | les trois univers : vignettes animées (SVG, CSS, SMIL), projets, TP et photos |
| `assets/css/` | les styles |
| `assets/img` · `assets/video` · `assets/pdf` | médias, rapports et certificat |

Site statique, sans étape de build : chaque push sur `main` est publié par GitHub Pages. Aperçu en local :
